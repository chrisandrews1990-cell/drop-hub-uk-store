FREE DROPSHIPPING STOREFRONT
============================

1. Open index.html in your browser to preview the store.
2. Edit products.js to change products, prices, categories and supplier references.
3. Edit index.html to rename the brand and change page wording.
4. Replace the legal-page placeholders with your real business details before launch.
5. Publish free using GitHub Pages or Netlify.
6. Connect a payment provider before accepting orders.
7. This version uses MANUAL dropshipping fulfilment. Automated product/order syncing generally requires supplier apps or ecommerce services.

Files:
- index.html
- styles.css
- products.js
- app.js
- privacy.html
- returns.html
- terms.html
- supplier-guide.html
